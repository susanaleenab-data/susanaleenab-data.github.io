Problem & goal

Explore patterns in a student lifestyle dataset and build a demonstration classifier for dataset-defined stress categories. The application is an educational ML project, not a clinical stress assessment.

Dataset & exploration

Worked with a 2,000-row student dataset. Explored study, sleep, and physical-activity patterns using exploratory data analysis and visualizations.

Modeling approach

Trained and evaluated Random Forest and Decision Tree classifiers using a 1,600 training / 400 test split. Examined classification reports, confusion matrix, and feature importance. Tools included Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Streamlit, and GitHub.

Results & what they mean

Both models achieved 100% test accuracy on this dataset. A simple decision tree recovered study/sleep threshold rules, suggesting highly deterministic labels. This perfect score should not be taken as evidence of reliable real-world stress prediction or generalization to new populations.

Live application

The deployed Streamlit interface lets visitors explore the project and its predictions. The main learning outcome is demonstrating data analysis, classification, evaluation, and critical interpretation of model performance.

Limitations

Dataset source details and any real-world validation should be verified before stronger claims are made. The project does not diagnose stress or provide medical advice.
